● A plugin for Claude Code · no API key

Every prompt, coached.

coachline sits beside Claude Code. It shows what each prompt leaves out, puts a sharper one in your prompt box, and learns which prompts cost you rework. Claude does the analysis on your own subscription.

/plugin marketplace add teransarathchandra/coachline

How it works

Two commands, then keep working the way you do.

01

Install, and the panel opens

In Claude Code, add the marketplace and install. The panel opens beside the conversation at once: no restart, no API key.

02

Send a prompt, see it coached

While Claude works on it, the panel shows what to improve and an enhanced prompt, with [ASK] where only you know the answer.

03

Start something new, get the right tools

Skills you already have that fit, then tools, docs and reference sites from the web, each one checked first.

Private by design

Your prompts are yours. Here is exactly what happens to them.

No API key

Claude runs through your own Claude Code login. No telemetry.

Redacted first

Emails, keys and tokens are removed before anything is sent. Keep a project out entirely with llm-off.txt.

Checked on your machine

Counts are recomputed, skill names must exist, and every link must load before you see it.

Gone in one command

/coach forget deletes what it learned; /coach panel-ai off keeps only the local hints.
